WHAT'S NEW IN 1.6

Six headline upgrades

Each change ships in the same local-first package: no accounts, no telemetry, no cloud requirement.

AGENTS

Swarm 2.0

Team rooms now field up to six read-only specialists across eight roles — Researchers, Analysts, Reviewers, Investigators, Builders, Testers, Documenters, and Strategists — and the AI lead closes every run with a published synthesis verdict.

  • Up to 6 workers per room (was 3)
  • Lead synthesis: agreement, contradictions, next steps
  • Doubled collaboration limits and two anonymous helper calls
WORKFLOW

Marathon quality budgets

U-tier engineering now reaches U10 at 72 active hours — a genuine one-to-three-day scale. Every request re-states the authoritative elapsed time, so long tasks never drift into guesswork, idling, or hallucinated progress.

  • S1–S4 quick fixes · H1–H4 contained work · U1–U10 marathons
  • Time facts computed fresh on every turn
  • Same edit size and care as an H-tier pass, all the way through
COMPANION

The otter companion

While Sonderr works — including through the final streamed response — a small otter now surfaces in the status line with a gentle swim animation, so you always know the local runtime is busy on your behalf.

TASKS

Task lists 2.0

Todo items now carry live evidence notes: the next action for open milestones, the verifying evidence for completed ones. Marathon tasks use milestone-sized items instead of filler keysteps, and the visible progress bar reflects real verification.

STUDIOS

Sonderr Studios — specialized & RC

Studios graduates from beta to RC and goes specialized: seven dedicated studios — Websites, Apps, Documents (print-ready PDFs), Design, Projects, Developer, and Bounty — each with its own milestones, canvas, and quality bar for real deliverables.

STUDIO CREW

Two specialists, phase-aware

Every Studios work turn fields exactly two specialists matched to the craft, and the crew is phase-aware: plan, build, and review turns hand each worker a different specific task for what needs to happen now. Each studio also carries a craft playbook — five professional rules and a definition of done the work must meet.

  • Exactly 2 workers, 1 specific task each, every phase
  • 7 craft playbooks with definitions of done
  • Lead synthesizes evidence and makes every edit
RELEASES

This Release Center

Every launch now greets you with the current release announcement, and the release notes live on their own hub — this page — with the archive one click away in the sidebar.

STUDIOS, SPECIALIZED

Seven studios. One crew. Every craft.

Documents, design, websites, apps, projects — each studio is specialized for its craft, every build runs with two specialists who each carry one specific task, and every deliverable is held to a written craft standard with a definition of done.

SECURITY IN 1.6

Hardening that rides along

The update gate still verifies every install against the official GitHub release before the workspace unlocks.

  • Update checks remain pinned, size-capped, and fail-closed; development checkouts are never silently overwritten.
  • Workspace tooling keeps symlink-safe, exclusive temp-file writes and path containment from the 1.5.x line.
  • Swarm rooms stay read-only for workers; synthesis and votes are clearly labeled AI assessments, never authorization.
  • Wallet, email, and MCP confirmations keep their explicit per-action cards; a general request is never blanket approval.
UPDATING

How updates reach you

1

Launch check

Sonderr compares your build against the official release on every start. When an update is required, the gate walks you through it — it cannot be dismissed until your install is verified current.

2

One-command install

Managed installs update themselves in place. Fresh installs take one command from the release page: curl -fsSL https://raw.githubusercontent.com/dxn111/sonderr/main/install.sh | sh

3

Announced every launch

The v1.6 announcement greets you on startup; the full notes live here, and past announcements (including the Sonderr-v1 SLM film) stay in the sidebar archive.
