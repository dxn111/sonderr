## When to use
- Writing or improving landing pages, product pages, ad copy, taglines, onboarding text, value propositions.

## Approach
Clarity converts; cleverness decorates. The reader spends 3 seconds deciding whether the page is for them — the headline and subhead must answer "what is it, what does it do for me" before anything else.

## Steps
1. Nail the message hierarchy first: primary outcome (headline), mechanism (subhead), proof (social/numbers), objection-handling (FAQ), action (CTA). Get these as plain sentences before polishing words.
2. Write to one specific reader and their context; "everyone" messaging converts nobody. Name the outcome, not the feature ("Ship in half the time", not "AI-powered workflow platform").
3. Keep the hero copy under ~12 words headline, ~25 words subhead; body sections scan as claim → evidence → micro-CTA.
4. Cut adverbs, superlatives, and buzzwords ("revolutionary", "seamless"); replace each with a concrete fact or number.
5. Produce 3 distinct variants (outcome-led, problem-led, proof-led) so the user can pick, delivered in one markdown file organized by section.
6. Present the copy file with present_file; note where each block goes on the page.

## Pitfalls
- Feature lists with no benefit translation; five different CTAs competing on one page.
- Copy that describes the product category instead of why this one wins.

## Verify
- Trace every factual claim, number, testimonial, and comparison to supplied evidence; remove inventions.
- Read the page from the target reader's point of view and check that the CTA matches the actual product flow.
- Deliver the final copy by page section and identify any claim that still needs owner approval.
